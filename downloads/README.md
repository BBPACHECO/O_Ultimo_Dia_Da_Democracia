# Versão Android — gráficos suavizados, zumbis e diálogos

[Baixar APK v0.4.0](https://github.com/BBPACHECO/O_Ultimo_Dia_Da_Democracia/raw/refs/heads/main/downloads/o-ultimo-dia-v0.4.0.apk)

1. Abra o link no celular Android e baixe o arquivo.
2. Toque no APK baixado. Se solicitado, permita a instalação para o aplicativo usado para abri-lo.
3. Abra **O Último Dia da Democracia** pelo ícone instalado e use o celular na horizontal.

Novidades: personagens com formas arredondadas e proporções mais naturais, árvores e objetos suavizados, texturas discretas e iluminação revista. Os zumbis continuam de verde e amarelo, com combate e diálogos preservados. **VISÃO** alterna entre câmera tática e terceira pessoa. O jogo é nativo e funciona offline.

No menu ou na pausa, escolha **Gráficos: Suave** para antisserrilhamento e sombras, ou **Leve** para reduzir o custo desses efeitos. A preferência fica salva. Os modelos novos aparecem nos dois modos.

Requisitos: Android 7.0 ou superior, processador ARM de 32 ou 64 bits e OpenGL ES 3.0. Esta versão usa assinatura de desenvolvimento. A instalação em um aparelho físico ainda não foi validada.

O arquivo `.sha256` permite conferir a integridade do download. Na raiz do repositório:

```bash
sha256sum -c downloads/o-ultimo-dia-v0.4.0.apk.sha256
```

Use **0.4.0** para esta atualização. Pode instalar por cima da 0.3.1, preservando o progresso. Se já derrotou inimigos no save, comece uma nova missão para encontrar todos os zumbis ativos. A versão 0.2.0 foi testada pelo usuário no aparelho; o desempenho dos gráficos novos ainda precisa desse teste.
