# Versão Android — ação, diálogos e câmera em três quartos

[Baixar APK v0.3.0](https://github.com/BBPACHECO/O_Ultimo_Dia_Da_Democracia/raw/refs/heads/main/downloads/o-ultimo-dia-v0.3.0.apk)

1. Abra o link no celular Android e baixe o arquivo.
2. Toque no APK baixado. Se solicitado, permita a instalação para o aplicativo usado para abri-lo.
3. Abra **O Último Dia da Democracia** pelo ícone instalado e use o celular na horizontal.

Novidades: guardas humanos que perseguem e atacam, defesa corpo a corpo pelo botão **ATACAR**, saúde e diálogos com Lia, Inês e Tomás. Visual em três quartos com paleta e vegetação inspiradas na referência enviada, com arte original. **VISÃO** alterna entre câmera tática e terceira pessoa. O jogo é nativo e funciona offline.

Requisitos: Android 7.0 ou superior, processador ARM de 32 ou 64 bits e OpenGL ES 3.0. Esta versão usa assinatura de desenvolvimento. A instalação em um aparelho físico ainda não foi validada.

O arquivo `.sha256` permite conferir a integridade do download. Na raiz do repositório:

```bash
sha256sum -c downloads/o-ultimo-dia-v0.3.0.apk.sha256
```

Use **0.3.0** para testar esta atualização. O código de versão foi aumentado para atualizar a 0.2.0 sem desinstalar. Saves antigos migram para o novo formato com saúde, guardas derrotados e conversas concluídas. A versão 0.2.0 foi testada pelo usuário no aparelho; os novos recursos da 0.3.0 ainda precisam desse teste.
