# Versão de teste Android — terceira pessoa

[Baixar APK 3D v0.2.0](https://github.com/BBPACHECO/O_Ultimo_Dia_Da_Democracia/raw/refs/heads/main/downloads/o-ultimo-dia-v0.2.0.apk)

1. Abra o link no celular Android e baixe o arquivo.
2. Toque no APK baixado. Se solicitado, permita a instalação para o aplicativo usado para abri-lo.
3. Abra **O Último Dia da Democracia** pelo ícone instalado e use o celular na horizontal.

Esta é a versão **3D em terceira pessoa**: joystick para andar, arrastar à direita para controlar a câmera, botão para correr e ação para recolher provas ou transmitir. O jogo é nativo e funciona offline.

Requisitos: Android 7.0 ou superior, processador ARM de 32 ou 64 bits e OpenGL ES 3.0. Esta versão usa assinatura de desenvolvimento. A instalação em um aparelho físico ainda não foi validada.

O arquivo `.sha256` permite conferir a integridade do download. Na raiz do repositório:

```bash
sha256sum -c downloads/o-ultimo-dia-v0.2.0.apk.sha256
```

O APK 0.1.0 é o protótipo anterior de alternativas. Use **0.2.0** para a experiência em terceira pessoa. O código de versão foi aumentado para permitir atualizar a versão anterior sem desinstalar.
