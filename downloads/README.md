# Versão Android — zumbis, ação e diálogos

[Baixar APK v0.3.1](https://github.com/BBPACHECO/O_Ultimo_Dia_Da_Democracia/raw/refs/heads/main/downloads/o-ultimo-dia-v0.3.1.apk)

1. Abra o link no celular Android e baixe o arquivo.
2. Toque no APK baixado. Se solicitado, permita a instalação para o aplicativo usado para abri-lo.
3. Abra **O Último Dia da Democracia** pelo ícone instalado e use o celular na horizontal.

Novidades: zumbis com camisas verdes e amarelas, postura e movimentação de mortos-vivos, combate pelo botão **ATACAR** e diálogos atualizados com Lia, Inês e Tomás. **VISÃO** alterna entre câmera tática e terceira pessoa. O jogo é nativo e funciona offline.

Requisitos: Android 7.0 ou superior, processador ARM de 32 ou 64 bits e OpenGL ES 3.0. Esta versão usa assinatura de desenvolvimento. A instalação em um aparelho físico ainda não foi validada.

O arquivo `.sha256` permite conferir a integridade do download. Na raiz do repositório:

```bash
sha256sum -c downloads/o-ultimo-dia-v0.3.1.apk.sha256
```

Use **0.3.1** para esta atualização. Pode instalar por cima da 0.3.0, preservando o progresso. Se já derrotou inimigos no save, comece uma nova missão para encontrar todos os zumbis ativos. A versão 0.2.0 foi testada pelo usuário no aparelho; os novos recursos ainda precisam desse teste.
